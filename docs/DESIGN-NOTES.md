# §확정 — 사용자가 정한 것

## 결정 1 — 인물 색 15곳은 **스킨 불변** (2026-08-06 확정)

> **용의자 식별색은 정보지 장식이 아니다. 도시에 스킨이 물들이지 않는다.**

```
대상   App.jsx PEOPLE 다섯 × c1 · color · c2  = 15곳
취급   데이터. 토큰화 대상이 아니고 --game-* 폴백도 끼우지 않는다
```

**근거**: 플레이어는 격자·평면도·관계도에서 **색으로 사람을 식별한다.** 스킨이
색을 바꾸면 식별이 흔들린다 — 그건 꾸미기가 아니라 **정보 파괴**다.
`MEMORY.md` §절대 규칙의 「유용도 시각 구분 금지」와 같은 축이다: 색이 **뜻을
가지는 자리**는 장식 레이어가 만지지 않는다.

⛳ **그래서 감사 #9 의 「저작 판단 대기」는 해제됐다** — 토큰화 대상은
**크롬 8곳뿐**이고 인물 색 15곳은 **범위 밖으로 확정**이다. 대기 항목이 아니다.

## 결정 2 — 중간 공개는 **3단계 무게 체계 + A/B** (2026-08-06 확정)

> 아래가 §구상의 인터루드 초안을 **대체한다.** 초안은 이력으로 남긴다(§구상).

```
대 (전체 화면 인터루드)   새 장 진입 · 트릭 인상 붕괴 · 지목 직전 — 사건이 꺾이는 곳
중 (반화면 카드 팝)       핵심 물증 확보 · 확보 단어가 공란을 처음 여는 순간
소 (토스트 개선)          일반 조사 결과 — 흐름을 끊지 않는다
```

- **근거**: 전 공개가 같은 무게면 **무게가 안 실린다.** 감사 축2의 밀도 원리와
  같은 말이다 — 초안의 *"무게를 아무 데나 주면 무게가 없어진다"* 를 **3단으로
  구조화한 것**이지 뒤집은 것이 아니다.
- **중↔대 경계는 설정값으로** — 테스터 A/B 대상. 절반은 3단계, 절반은 **중을
  대로 승격**해서 돌린다.
- **`PLAYTEST.md` 질문 등재**: *"연출이 몰입을 도왔나, 흐름을 끊었나"*
- **트릭 붕괴의 판정은 목록이 아니라 규칙 검토** — `illusion.brokenBy` 도달
  시점. **가능하면 규칙으로**(기계 판정). 구현은 **밀도·중간 공개 배치**에서.

⛳ **이 절은 결정 기록이지 구현이 아니다.** 밀도·중간 공개 배치의 **입구가
열렸다**는 기록이다.

## ⏭ ~~인터루드 급 공개 후보~~ (2026-08-05 · 사용자 구상) — **대체됐다**

> ⛔ **이 절은 이력이다. 살아 있는 것은 §확정 결정 2(3단계 무게 체계)다.**
> 아래 후보 셋은 그대로 **「대」 단계**가 됐고, 초안에 없던 **「중」·「소」**가
> 붙었다. 제약 둘(즉시 스킵 · 일반 조사 결과는 승격 금지)은 **살아 있다** —
> 결정 2의 「소」가 그 두 번째 제약을 그대로 옮긴 것이다.

전체 화면을 덮는 인터루드 문법(프롤로그·에필로그가 쓰는 그것)으로 **승격할
후보** 셋:

```
① 새 장 진입 서술문
② 트릭 인상이 깨지는 순간
③ 지목 직전
```

### 검토 과제 — ②를 목록이 아니라 규칙으로 낼 수 있나

②가 **저작 목록**(사건마다 사람이 골라 적는 것)이면 사건이 늘 때마다 자라고,
빠뜨리면 조용하다. **규칙**으로 낼 수 있으면 그 문제가 없다:

> `illusion.brokenBy` 에 도달하는 시점을 기계가 판정할 수 있나?

가능하면 **목록이 아니라 규칙으로 간다.** (`inShipGate` 가 태그가 아니라 규칙인
것과 같은 자리 — 손으로 태그하면 새 사건에서 조용히 빠진다.)

### 제약 둘

```
⛔ 전체 화면 인터루드는 **탭/클릭 즉시 스킵 가능**해야 한다
⛔ 일반 조사 결과(확보 단어 +1 · 물증 카드)는 **승격 대상이 아니다**
   — 도구 화면의 리듬을 끊지 않는다
```

두 번째가 이 구상의 경계다. **무게를 아무 데나 주면 무게가 없어진다** — 승격은
드물어야 승격이다.

### 감사와의 연결

**`docs/DESIGN-AUDIT-SPEC.md` §1 축2** 에 측정 항목이 걸려 있다 — 중간 공개(추가
단서 공개 · 트릭 인상 붕괴 · 장 전환)가 **지금 어떤 무게로 렌더되는지**를 4폭에서
재고, 프롤로그/에필로그의 전체 화면 문법과 대비한다. **결과가 앉을 곳**은
`docs/DESIGN-AUDIT-2026-08.md`(감사 산출물, 감사가 만든다)다.

> ⛳ **이 줄이 한동안 틀려 있었다** (2026-08-05 정정). *지시서*(무엇을 잴지)와
> *산출물*(잰 결과)을 섞어서 「`DESIGN-AUDIT-2026-08.md` 에 항목이 걸려 있다」로
> 적었는데, 그 파일은 **감사가 끝나야 생긴다.** 없는 파일을 근거처럼 가리키고
> 있었던 셈이다.

**감사가 「중간 공개에 무게가 없다」를 실측하면 그것이 이 구상의 착수 근거다.**
반대로 이미 무게가 있다고 나오면 승격은 필요 없다 — **재고 나서 짓는다.**
