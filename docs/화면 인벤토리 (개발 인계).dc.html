이 문서는 "무엇이 어떻게 생겼는가"만 다룹니다. 게임 규칙·판정·채점·검증·사건 데이터 구조는 별도 문서. 값은 실제 구현 기준이며 브리프와 다를 경우 실제 값을 적었습니다. 단일 파일 추리게임.dc.html + 자식 추리판.dc.html(상황판).

2. 화면별 컴포넌트 (renderVals 빌더 기준)

빌더 / 컴포넌트역할
buildSections보고서 장(章) 아코디언. 장별 공란(blank) 트리거·드롭다운·확보단어 선택.
buildStatements진술 원문 정독. 좌측 레일(132–172px) + 본문. 접힘 행: 아바타·이름·성별연령·직업·관계칩·미리보기.
segsFor텍스트를 하이라이트 구간으로 분할(진술·프롤로그·추가진술 공용). 드래그 선택 툴바 selTb.
buildFloorplan현장 평면도. 공간 박스·고정물·인물 마커·시간 세그먼티드·현장 조사 기록(narrations).
buildGrid주장 대조 격자(현장 "도식" 탭). 행=인물, 열=시간대.
buildProfiles / buildProfileDetail용의자 카드 격자 + 상세(주장·발견 단서·미확인 슬롯·verdict 칩).
buildGraph (관계 그래프)view:'graph'. 게임이 그리는 확정 관계망 — 노드+간선, 실선. 조사로만 간선 등장(추측 안 그림).
추리판 (상황판)view:'board' 자식 DC. 플레이어 자유 배치 판단 캔버스 — 점선 연결.
buildInvestigation조사 기록 목록. 물증 나온 항목은 클릭 시 물증 카드.
buildMemos메모 저장소(단일). 2열 그리드·정렬(최신/대상)·검색·수집함 토글·층위 라벨.
buildRef표기 안내(상태 레퍼런스) — 핸드오프 문서.
buildOverview사건 개요. 프롤로그 산문(드래그 인용) + 브리핑 표(항목별 인용·복사).
물증 카드(openTerm)발견·기록 2필드 좌측라벨 2단. 확장(메시지/문서)은 하단 덧붙임.
인용 팝오버(quotePicker)수집함 2개+일 때 "어느 메모에" 선택 모달.

3. 컴포넌트별 상태 (표기 안내 기준 + 누락분)

보고서 장(章)

잠김(번호만 · 제목/라벨/유형/개수 가림) · 열림 · 완성(자동, 잠김) · 완성 · 재개봉 사용됨. 재개봉 1회. 실시간 채점·모순 경고 없음(최종 제출만 확정).

공란(blank)

비어 있음 · 채움. 완성 전까지 자유 수정. 닫힘후보=드롭다운, 확보후보=단어창고.

하이라이트 (드래그) — 4종

표시(중립·azure) · 확인 · 의심 · 모순. 표시는 툴바 첫 위치·원탭, 재선택 후 나머지 3종으로 승급. 배경 30–32% + 밑줄 2px. 툴바: 4마크 · ✕지우기 · 인용 · 복사.

격자 셀 마킹 — 3종 (유지)

확인 · 의심 · 모순. (하이라이트와 색 어휘 공유, 표시 없음.)

메모

수집함 인용 모으는 중 / 인용 모으기(메모별 독립 토글) · 인용 카드 층위(주장·azure / 확정·green) · 대상 지정/미지정 · 검색 결과 있음/없음 · 편집/읽기. 제목 필드 없음(번호 #N + 본문 전체 검색).

물증 카드

기본(발견·기록) / 확장 있음(메시지·문서 하단 덧붙임). 기록은 3인칭 관찰만.

평면도 공간·고정물

미조사 / 조사됨 / 빈손(색 구분) · 미공개(availableAfter, 예: 별채는 1장 완성 전 지도에 없음, 공개 시 "공개" 칩). 인물 마커=인물 색 점.

프로필

신규 배지(열람 시 소거) · 발견 단서 유무 · 미확인 슬롯 · verdict 칩(플레이어 표기). 유죄 판정·레드헤링 시각 구분 없음.

provenance 배지 (전역)

"N장 완성으로 공개/갱신" — 진술 추가문단·사건 개요(사망시각 갱신+취소선)·평면도 후공개 공간에 영구 표시. + 사이드바 안 읽음 점(state.unread).

5. Vector DS 사용분 vs 신규

Vector DS 그대로이 게임에서 신규
셸(.app/.sidebar/.main/.tabbar), nav-item, 세그먼티드, 스크롤바, Button(x-import), 모달/scrim, 색·서피스·보더·반경·타이포(.v-*) 토큰--g-* 상태색, 하이라이트 4종, 보고서 장 아코디언, 주장 대조 격자, 평면도(좌표 자동), 물증 카드 2단, 메모 수집함/팝오버, 진술 정독 조판, provenance 배지, 인물 색 세트, 상황판(추리판)

토큰은 전부 var(--*) 참조, 신규는 [data-surface="vector"] 스코프에만 추가. 새 토큰 체계 없음.

특히 확인 요청 4건

① 격자 열 머리 ↔ 지도 시간 — 독립. 열 머리는 정적 라벨이며 클릭해도 지도 시간이 바뀌지 않습니다. 시간 이동은 평면도 위 별도 세그먼티드에서만(격자는 "도식" 탭, 평면도는 "평면도" 탭 — 동시 표시 안 함). 과거의 "열 클릭 → 지도 점프"는 제거됨.

② 격자 빈 셀 — "언급 없음" (ui.noClaim). — 아님. 침묵=은폐 메커니즘을 드러내기 위함.

③ 조사 결과 자동 표시 — 없음. 격자는 CLAIMS(고정 주장) + CLAIM_REVEALS(항 완성 시 주장 추가 + 신규 배지)만 반영. 조사로 물증을 얻어도 셀에 자동 마킹하지 않음 → 제거한 모순 경고의 부활 아님. 셀 마킹은 플레이어만.

④ 읽기/UI 서체 차이 — 유지됨(위 4장 표 참조).
