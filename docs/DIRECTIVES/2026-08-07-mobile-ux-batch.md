## 2부 — 평면도
④ 「현재」 탭: 과거 탭 = 주장의 재생(현행, "지도는 판정하지 않습니다") /
   현재 탭 = 사실의 현장 — 인물 배지 제거, 조사 마커(장소·물건 대상 액션)와
   조사 상태(빗금=미조사 · ✓=완료)만
⑤ 마커 탭 → 하단 시트: 미조사 "조사명 · 1회 사용 · [조사한다]" — 기존 조사
   실행 함수·확인 문법 재사용(실행 경로 정본은 하나, 렌즈만 추가) / 완료
   "확보 물증 + [조사 기록으로]" — 물증 상세 시트 재사용
⑥ 예산: 현재 탭 범례 자리에 「남은 조사 N회」
⑦⑧ 방 안 범례(점+이름 목록) — 미리보기·확대 공유 컴포넌트 [완료]
⑨ 현장 개요 — bbox 잘라내기 + 부족분만 늘림(CSS max) [완료]

2부 검증: 극장 로비 전원 + 미술관 + 산장 각 375 · 고배율(~275%) 필수 ·
현재 탭 실행 = 조사 목록 경로와 같은 함수 · focus-check · 게이트 · 배포.
