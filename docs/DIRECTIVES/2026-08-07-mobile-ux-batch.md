## 2부 — 평면도
④ 「현재」 탭: 과거 탭 = 주장의 재생(현행, "지도는 판정하지 않습니다") /
   현재 탭 = 사실의 현장 — 인물 배지 제거, 조사 마커(장소·물건 대상 액션)와
   조사 상태(빗금=미조사 · ✓=완료)만
⑤ 마커 탭 → 하단 시트: 미조사 "조사명 · 1회 사용 · [조사한다]" — 기존 조사
   실행 함수·확인 문법 재사용(실행 경로 정본은 하나, 렌즈만 추가) / 완료
   "확보 물증 + [조사 기록으로]" — 물증 상세 시트 재사용
⑥ 예산: 현재 탭 범례 자리에 「남은 조사 N회」
⑦⑧ 방 안 범례(점+이름 목록) — 미리보기·확대 공유 컴포넌트 [완료]
⑨ 현장 개요 — bbox 잘라내기 + 부족분만 늘림(CSS max) [완료]

2부 검증: 극장 로비 전원 + 미술관 + 산장 각 375 · 고배율(~275%) 필수 ·

## 2부-b — 모바일 내비 구멍 둘 (2026-08-07 경훈 실기기 보고 · 추가분)

① **좁은 폭에 사건을 빠져나갈 길이 없다.** 「더 보기」 시트에 「사건 목록으로」 추가.
   ‹ 는 홈이 아니라 «이전 화면»으로 가고 보고서가 고정점이다(열 번 눌러도 그대로).
② **기어 위치.** 실측 결과 기어는 네 화면 전부에 1개 있고 패널도 전부 열린다 —
   **미표시 결함이 아니라 위치 불일치**다(현행 뷰헤더 `315,46` · 기대 디테일바).
   ⛳ 상단바 우측 `319,0` 은 「나란히 보기」가 이미 쓴다 — 옮기면 그 버튼의 행선지가
   딸려 온다. **위치는 경훈 판정 대기.**

### ③-b 포기 경로 — 의미론 (경훈 결정)

「더 보기」 시트에 **「사건 그만두기」**. 확인 대화 뒤 목록 복귀 + 해당 사건 진행 초기화.

```
확인 문안   "진행은 저장되지 않으며 정답은 공개되지 않습니다.
            나중에 처음부터 다시 할 수 있습니다."
3막 해설    «지목 경로에서만» 열린다 — 포기로는 절대 안 열린다
완료 사건    목록에 완료 표시 · 재입장 시 3막 «열람»(재플레이 아님)
```

⛔ **포기가 정답을 공개하지 않는다는 것이 이 절의 핵심이다.** 포기를 「답 보기」의
샛길로 만들면 §절대 규칙(게임이 판단에 대해 하는 말은 최종 채점 하나뿐)이 무너진다.
그래서 확인 문안이 «정답은 공개되지 않습니다»를 명시한다 — 기대를 먼저 자른다.

⛳ **새 로직을 안 지었다** — `goHome()`·`abandon()`·확인 대화가 이미 있고 데스크톱
사이드바가 그것을 쓴다. 좁은 폭에 **입구가 없었을 뿐**이다.
