## 1. ⑦-b 방 안 범례 충돌 — 인물 목록 vs 방 이름·설비

- 수리: 범례 시작 y 를 **방 이름 라벨 아래로** — 고정 오프셋이 아니라 **방 이름의
  실측 높이 기준**(시스템 글꼴 배율이 얹혀도 안 겹치게).
- 설비 마커와의 충돌도 같은 원리로 회피 — 범례 영역과 마커 좌표가 충돌하면 마커를
  비는 사분면으로 이동하거나, 범례 뒤 z-order + 불투명 배경 중 **실측으로** 골라라.
- 계측 확장: 겹침 검사를 인물↔인물에서 다음 쌍 **전수**로 —
  범례↔방이름 · 범례↔설비마커 · 범례↔미조사배지.
  이번 케이스(미술관 로비 5인)를 **심어서**: 수리 전 exit 1 · 후 exit 0.
- ⚠ 계측 이력 주의: 이 검사기는 **일곱 번 틀렸다**(svg 오포착 · opacity 필터 ·
  computed 전이 고정 · 문/창 라벨 오포함 · aria/title · isHome 정규식 · 탭바 판정).
  **인물 알약만 거르는 필터**와 **inline 정본** 원칙을 그대로 쓴다.

## 2. ② 기어 재배치 (재판정 — 경훈 요구 확정)

- 좁은 폭에서 기어를 **상단 바 우측(디테일바 자리, 기존 `319,0` 자리)**으로.
- **「나란히 보기」는 좁은 폭에서 제거** — 375 에서 두 패널을 나란히 놓을 폭이 없어
  기능 자체가 무의미하다. **데스크톱은 현행 유지.**
- `68a8d81` 의 「전 화면 기어 1 보장」 검사에 **위치 조건 추가** —
  좁은 폭에서 기어가 **상단 바 안에** 있는가.
- 뷰헤더 쪽 기어는 좁은 폭에서 제거(전 화면 1개 보장 유지). 데스크톱은 뷰헤더 현행.

## 3. ⑨-c 미리보기 높이 상향 (⑦-b 이후 착수)

- 현행 ⑨ⓑ 합격선(34px 방 최소 높이)이 보수적 — 375 에서 도면 아래 빈 공간이
  화면의 절반이다.
- 새 목표: **도면 하단 여백 ≤ (범례 + 캡션 높이)** — 시간대 탭 아래부터 하단 범례
  위까지를 도면이 쓴다.
- 늘림은 ⑨ⓑ 의 방식 유지 — **배수 상수 금지**, CSS `max()` 부족분 계산.
- 넷 사건(미술관 1.64 · 극장 2.40 · 연습실 0.84 · 산장) 재실측 —
  **세로형(연습실)이 목표 높이에서 과연장되지 않는지 상한도 확인.**

## 4. 검증 일괄

- 넷 사건 × 전 시간대 × 375 — 특히 **5인 방 전수**. 충돌 쌍 계측 0.
