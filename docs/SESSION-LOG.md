### 브레인스토밍 & 큰 결정
- **협박대상 조유리 vs 김채원**: MEMORY 표엔 "결정"으로 적혀 있었으나 실은 논의 중이던
  안. 원문 대조 결과 김채원은 조사 0회로 채워지는 중복 공란 + 유료 조사(유리 협박문자)가
  답안지에 안 남음 → 조유리. 답이 아니라 문장틀을 고침
- **4장 5공란 확장 기각**: 심증 부문 빈약을 공범(김채원) 추가로 풀려던 안 → 기각.
  공범은 누설·검증부담(유일성이 인물 쌍으로)·난이도(예산 경고 악화) 전부 나쁨.
  대신 공범 라벨 자체 폐기 → 심증 3라벨이 실제 3공란과 일치
- **Option A vs B (opportunity 도출)**: presence 계층은 추가로만(격자 생성+무고 보장),
  guilt·난이도는 손 fact 유지. 건드리면 "기대 5회"가 미검증 영역으로 감
- **슬롯 4슬롯 정본**: 엔진 5슬롯 폐기. 격자는 플레이어가 보는 것과 같아야 함
- **DC 툴이 프로토타입 마스터**: 리포 편집이 DC 툴에 안 감을 export 대조로 확인.
  양방향 split-brain (리포=데이터수정 / DC툴=floorplan). 내 데이터 수정은 changeset 으로 넘김
