*"`main` 에 push 하면 **자동으로 나간다**"* 라고 적고 있었다 — **거짓이었다.**

원인이 **둘**이고 둘 다 대시보드 설정이었다:

```
Root Directory = app     → 루트 vercel.json 이 통째로 무시됨
                         → 배포가 9단 게이트를 **한 번도 안 돌았다** (앱 build 만 돌았다)
Install Command Override = 'npm install'   ← --include=dev 가 없다
                         → Vercel 은 NODE_ENV=production 이라 devDependencies 를 건너뛴다
                         → engine 의 js-yaml(devDep)이 안 깔림 → npm run case 사망
```

★ **왜 tsx 는 되고 js-yaml 만 안 됐나** — 「Include files outside the root directory」가
Enabled 라 `engine/` 파일 자체는 있었다. 파일은 있고 **패키지만 없는** 모양이라
원인이 안 보였다.

★ **깨끗한 클론으로 모사해서 저장소 무결을 먼저 증명했다** — `npm install --include=dev`
가 js-yaml 을 정상 설치한다. 그래서 원인을 저장소 밖으로 몰아넣을 수 있었다.

⚠ **`"github": { "silent": true }` 가 실패를 GitHub 커밋에 안 알리게 하고 있었다.**
18번이 조용히 실패한 이유다. `false` 로 돌렸다.

**사용자가 대시보드를 고쳤다** — Root Directory 비움 · Override 셋 해제 · Skip deployments 해제.

  따라 바뀐다. 두 벌이 안 생긴다
- **검증 실패 시 오류를 그대로 챗봇에 되붙일 수 있게** 복사 버튼을 준다.

- **일곱 번째 「이미 있는데 배선만 없던 것」** — `vite.config.ts` 에
  `engineResolver` 플러그인과 `@engine` alias 가 주석까지 달린 채 있었고
