## 잊지 말 것 — 살아 있는 결정

1. **엔진이 게임 로직의 정본이다.** 프로토타입은 이식 대상. `npm run build` = 사건 논리 검증.
2. **DC 툴 = 프로토타입 마스터.** 저장소 `추리게임.dc.html` 은 사본이다.
   **저장소에서 직접 고치지 말 것** — 재export 때 사라진다. 이번 통합의 비용이 정확히 그것이었다.
3. **4장 협박대상 = 조유리(오나경)**. 문장틀도 "입막음"→"약물로 붙들어"로 교정.
4. **공범 라벨 폐기.** 존재 자체가 "범인 외 1명"을 조사 0회에 누설. 진실세계 `accomplice`
   역할은 유지, 공란 라벨만 제거. 엔진·문서 전부 반영 완료, 프로토타입만 남음.
5. **상황판 = 상시 화이트보드** (필수). 브리프 §338 "5장 자동 전환"은 죽음.
6. **presence → 진술 도출** (Option A): 무고=진실 도출, 범인만 `claim`(거짓말).
   `opportunity` 는 아직 손 fact 유지 — presence 도출(Option B)은 플레이테스트 후 보류.
7. **런타임 LLM 0 / 게임은 최종 채점 전까지 완전 침묵** — 모든 신규 화면에서 확인.
8. **트릭은 이름표가 아니라 계약이다.** 원형을 늘리려면 `ARCHETYPES` 에 계약을 추가한다.
   이름만 늘리는 것은 아무것도 늘리지 않는다.
