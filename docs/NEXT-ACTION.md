## ⛔ 「`REVEALS` 부터 — 가장 쌈」은 **거짓이다** (2026-07-27)

앞선 워크로그가 엔진 재분리의 첫 타로 `REVEALS` 를 꼽았다. **잘못됐다.**
`REVEALS` 는 데이터 이동이 아니라 `INV_ACTIONS` 와 같은 **모델 충돌**이다.
`docs/MEMORY.md` 「REVEALS 불일치 (2026-07-24 발견)」가 이미 적어둔 것과 같은 사실이고,
우선순위 메모만 그것과 모순돼 있었다.

| 트리거 | 엔진 `reveals` | 앱 |
|---|---|---|
| 1장 완성 | `facts:[f_cause]` · `actions:[a_annex]` · narration | `targets:['search:annex']` · 유빈 flavor 진술 |
| 2장 완성 | `add_claims` 나경 「새벽에 다인 언니가 저한테도 전화를 했었어요」 | `CLAIM_REVEALS.s3` 나경 t1 「통화 중 (본인 주장)」 **+ 진술 2건** |
| 3장 완성 | `add_claims` 지안 「나경 걔가 요즘 돈 문제로…」 | **없음** |
| 4장 완성 | **없음** | `REVEALS.s4` 나경 「그 소문… 세라 언니 쪽이었죠」 |

화자가 다르고, 문안이 전부 다르다.** 옮기려면 어느 장이 무엇을 공개하고 누가

부수로 확인된 죽은 필드 둘: `REVEALS[].yield`·`statements[].y` 는 **어디서도 읽지

2026-07-25에 **감사 45건**을 청산했다. 그 과정에서 사용자가 물었다 —
*"그냥 프로토타입을 그대로 구현하고 수정할 것만 고치면 되는 거 아니냐."* **맞다.**

```
이식   원본 구간 하나 읽기 → 컴포넌트 하나 쓰기      ← 이제부터 이것만
수리   원본 찾기 → 앱 찾기 → 차이 판정 → 고침        ← 잘못 지었을 때만 필요
```

**남은 화면은 앱에 아예 없다. 대조할 게 없다.** 감사표를 다시 쓰지 않는다 —
대조가 필요하다는 것 자체가 이미 잘못 지었다는 뜻이다.

층은 둘로 가른다:

| 층 | 정본 |
|---|---|
| 클래스 · 구조 · 스타일 · **UI 문구** | **프로토타입** |
| 숫자 · 사실 · 어휘 · **사건 산문** | **엔진** |

**그리고 화면을 눈으로 본다.** 빌드·타입체크·검증기를 전부 통과한 채 살아 있던
결함이 **이틀에 여섯**이었다:

| 07-25 | 07-26 |
|---|---|
| `<style>` 토큰 블록 통째 누락 | **`--g-*` 가 셸 밖에서 전부 죽음** (모달 계열 전부) |

## 잊지 말 것 — 살아 있는 결정

1. ⚠️ **엔진은 지금 앱의 정본이 아니다** (2026-07-26). 사건 데이터가 `App.jsx` 에
   하드코딩돼 있다. 엔진·검증기는 그대로 살아 있고 빌드에도 걸려 있지만 **앱이
   읽지 않는다.** 사건 2번을 만들려면 다시 빼야 한다 — 아래 §다음 즉시 액션.
2. **DC 툴 = 이제 앱의 마스터다.** 프로토타입이 아니라 **앱**을 거기서 export 한다.
   `app/src/App.jsx` 를 직접 고치면 재export 때 사라진다 — 고친 것은 반드시
   `DC-SYNC-CHANGESET.md` 에 적는다.
3. **`DC-SYNC-CHANGESET.md` 는 여전히 살아 있다.** 1~7 + 예산은 2026-07-26 에
   앱에 재적용했고, **8번은 export 에서 해결돼 할 것이 없다**(11번). 9번만 남았다.
   DC 마스터는 그대로 옛 상태라 다음 export 때 1~7 이 **또** 되살아난다.
4. **태그라인은 프로토타입 그대로**(「모든 진술을 의심하라」).
5. **조사 예산은 `BUDGET` 상수 하나다**(`App.jsx`, 6). export 는 5 로 온다 —
   흩어진 하드코딩 8곳을 상수로 모아뒀으니 다음엔 한 줄만 고치면 된다.
6. **스타일은 인라인 우선이고 `S()` 로 감싼다.** 클래스 기반 스타일시트를 새로
   만들지 않는다(`app/src/styles.css` 는 폰트·키프레임·`pb-*` 만).
   > `relChip()` 이 `S()` 없이 문자열을 돌려줘서 **진술 화면이 통째로 죽었다.**
   > `style` 로 쓰이는 값은 반드시 객체다.
7. **런타임 LLM 0 / 게임은 최종 채점 전까지 완전 침묵.**
8. **트릭은 이름표가 아니라 계약이다.**
9. **평면도는 판정하지 않는다.** 확대·화살표·펄스 금지. 누를 수 있는 지점은
   커서와 테두리만 바뀐다.
10. **`localStorage.clear()` 를 검증에 쓰지 않는다.** 개발 서버와 같은 origin이면
    사용자의 실제 저장 데이터를 지운다 (2026-07-25에 한 번 날렸다).
11. **`--g-*` 는 `[data-surface="vector"]` 에 둔다 — 건드리지 않는다** (2026-07-26 갱신).
    한때 `:root` 로 올렸었다. 원본 `.dc.html` 은 `.app` 이 986행에서 닫히고
    홈·상세·모달이 **그 밖**이라 토큰이 죽었기 때문이다. **React export 는 전부
    한 트리 안에 넣어서 그 문제가 없다** — 홈(z=70)·상세(z=72)·모달(z=90) 셋 다
    실측으로 `--g-lock-mark` 가 산다. 지금 `:root` 로 올리면 export 와 갈라지고
    다음 재export 가 조용히 되돌린다.
    > 남는 교훈은 스코프가 아니라 **확인 방법**이다 — 셸 안에서만 보면 안 보인다.
12. **게임에 「실패」가 없다.** 원본 `caseStatus()` 는 `clear`/`inProgress`/`unplayed`
    셋뿐이고, **클리어는 다섯 장을 채운 순간**이다(제출이 아니다). 예산을 다 쓰고
    못 끝내도 「진행 중」이다. `CaseProgress.status` 의 `failed` 는 쓰이지 않는다.
13. ⚠️ **`app/src/case/*.ts` 는 지금 아무도 안 쓴다** (2026-07-26). 옛 손이식 앱의
    파생 계층(`score`·`suspect`·`board`)이고 새 엔트리에서 도달하지 않는다.
    같은 계산이 `App.jsx` 안에 있다. **엔진을 다시 뺄 때 되살릴 자리다.**
