## ⛏ 이식 방식이 바뀌었다 — 읽고 이 순서로 한다

2026-07-25에 **감사 45건**을 청산했다. 그 과정에서 사용자가 물었다 —
*"그냥 프로토타입을 그대로 구현하고 수정할 것만 고치면 되는 거 아니냐."* **맞다.**

```
이식   원본 구간 하나 읽기 → 컴포넌트 하나 쓰기      ← 이제부터 이것만
수리   원본 찾기 → 앱 찾기 → 차이 판정 → 고침        ← 잘못 지었을 때만 필요
```

**남은 화면은 앱에 아예 없다. 대조할 게 없다.** 감사표를 다시 쓰지 않는다 —
대조가 필요하다는 것 자체가 이미 잘못 지었다는 뜻이다.

| 층 | 정본 |

| 숫자 · 사실 · 어휘 · **사건 산문** | **엔진** |

**그리고 화면을 눈으로 본다.** 빌드·타입체크·검증기를 전부 통과한 채 살아 있던
결함이 **이틀에 여섯**이었다:

| 07-25 | 07-26 |
|---|---|

## 잊지 말 것 — 살아 있는 결정

1. **엔진이 게임 로직·데이터의 정본이다.** `npm run build` = 타입체크 + 사건 검증 + 앱 빌드.
2. **DC 툴 = 프로토타입 마스터.** 저장소 파일은 사본 — 직접 고치면 재export 때 사라진다.
   단 **읽는 것은 저장소 파일로 한다.** 이식에 DC 툴은 필요 없다.
3. **`DC-SYNC-CHANGESET.md` 가 8건으로 늘었다.** 5(인물명) · 6(지문 조사) · 7(아바타
   이니셜)이 전부 **같은 뿌리** — 이름을 바꿀 때 파생물이 안 따라갔다.
   **8(`--g-*` 토큰 스코프)은 다른 뿌리다** — 아래 11번. DC 툴을 여는 날 먼저 반영할 것.
4. **태그라인은 프로토타입 그대로**(「모든 진술을 의심하라」).
5. **조사 예산은 `Case.budget`**(6). 프로토타입 하드코딩 5는 낡은 값이다.
6. **앱 클래스는 `nl-` 접두사.** Vector 가 `.detail`·`.chip` 을 쓴다.
7. **런타임 LLM 0 / 게임은 최종 채점 전까지 완전 침묵.**
8. **트릭은 이름표가 아니라 계약이다.**
9. **평면도는 판정하지 않는다.** 확대·화살표·펄스 금지. 누를 수 있는 지점은
   커서와 테두리만 바뀐다.
10. **`localStorage.clear()` 를 검증에 쓰지 않는다.** 개발 서버와 같은 origin이면
    사용자의 실제 저장 데이터를 지운다 (2026-07-25에 한 번 날렸다).
11. **`--g-*` 는 `:root` 에 있다.** 원본은 `[data-surface="vector"]` 스코프인데
    **`.app` 이 986행에서 닫히고 홈·상세·모든 모달이 그 밖**이라 토큰이 죽는다.
    값이 아니라 스코프가 문제였다 — 셸 안에서만 확인하면 절대 안 보인다.
12. **게임에 「실패」가 없다.** 원본 `caseStatus()` 는 `clear`/`inProgress`/`unplayed`
    셋뿐이고, **클리어는 다섯 장을 채운 순간**이다(제출이 아니다). 예산을 다 쓰고
    못 끝내도 「진행 중」이다. `CaseProgress.status` 의 `failed` 는 쓰이지 않는다.
13. **채점은 `app/src/case/score.ts` 하나다.** 화면에 계산을 심으면 협동 모드에서
    서버 채점과 두 벌이 된다. 용의자 카드·상세도 `case/suspect.ts` 하나를 본다.
