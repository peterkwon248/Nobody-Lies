## 📐 상황판 기하 실측 (2026-07-27) — 스크린샷 없이 재는 법

**「보기 좋은가」의 절반은 치수다.** 스크린샷이 막혀도 `getBoundingClientRect` 로
띠 높이·여백·겹침은 전부 잴 수 있다. 두 세션 밀려 있던 항목을 이렇게 닫았다.

```
탭 띠        「상황판 1」 이름 입력 y=69..81 (h=12)
타임라인 띠   y=86..142  h=56  ← 월드 0..56. `pos.y<56` 레인 판정과 정확히 같다
바닥(평면도)  y=162      ← 월드 76
             ─────────────────────────
             여유 20px · 겹침 없음 (월드 76-56=20 과 일치)
```

**바닥 내부 스택** — 머리글(h15) → 시간대 띠(h28) → 도면(h475), 폭 760.
시간 마커 넷은 450px 등간격(전날 밤·새벽 3시·3–8시·오전)으로 띠 안에 든다.

> **「겹침은 피했다」가 실측으로 확인됐다.** 타임라인 띠 높이 56 과 레인 임계
> `pos.y<56` 이 같은 수라서, 바닥을 76 에 둔 것이 정확히 20px 을 남긴다.

> ⚠ **설명 못 한 10px 하나.** 시간대 띠의 `marginBottom` 은 `6px` 인데 도면까지
> 실측 간격이 **16px** 이다(도면 `marginTop:0` · 블록 레이아웃 · flex gap 없음).
> 보기에는 6px 보다 16px 이 낫고 결함으로 보이지 않아 그대로 뒀다 — **원인을
> 못 찾았다는 것만 적어둔다.**

**마커는 `<input>` 이라 `textContent` 로는 안 잡힌다** — 값이 `value` 에 있다.
DOM 으로 상황판을 훑을 때 이것 때문에 「마커가 없다」는 오진이 나온다.

> **남은 것은 색·대비·질감뿐이다.** 그건 창을 띄워야 보인다.
