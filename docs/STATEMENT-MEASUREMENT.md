★ **범인(최나림)과 무고한 문하린의 진술이 오프너 말고 한 글자도 안 다르다.**
이건 **설계대로**다(그림자 한 사람이 범인과 같은 동선 — `generate.ts §far` 주석).
물증으로만 갈리게 하려는 것이고, 그래서 **지금은 모양으로 안 튄다.**
⚠ 그런데 이것이 정확히 경훈이 짚은 위험의 근거다 — **전원이 기계적으로 동일해서
안전한 것**이지, 틀이 사람마다 갈리기 시작하면 **다른 것이 곧 신호**가 된다.

### 방출 틀 전수 — `generate.ts` `statementOf()` (`:1862`)

```
호출  buildWorld 의 인물 조립 (:2136)
      paragraphs: statementOf(범인 ? t.claim : innocentPresence(id), openerOf(i))
      gesture:    gestureOf(i)          ← 팔레트 gestures 에서
      voice:      없음                   ← 저작 필드인데 생성기가 안 채운다
```

문단은 **축의 칸마다 하나**다(다섯이 같은 개수 — 문단 수가 곧 범인 표시가 되는 것을
막는다). 각 문단은 `line()` 이 **네 갈래 중 하나**로 만든다:

```
갈래          조건                    틀 수    문안
first        첫 칸                     1      '{opener} {슬롯}에는 {장소}에 있었습니다.'
SAME         앞 칸과 같은 자리           3      '{슬롯}에도 같은 자리에 있었습니다.' 외 2
MOVE         자리를 옮김                3      '{슬롯}에는 자리를 옮겨 {장소}에 있었습니다.'
                                              '{슬롯}에는 {장소}에 가 있었습니다.'
                                              '{슬롯}에는 {장소}으로/로 옮겼습니다.'
absent       그 칸에 위치가 없음          1      '{슬롯}에는 그곳에 없었습니다.'
꼬리(far)    부지 밖 자리일 때 덧붙음      1      ' {홀}에서 걸어서 {N}분 거리입니다.'
```

**ko 갈래 총 9종.** 그리고 결정적인 것:

```
틀 선택 = SAME[nth % 3] · MOVE[nth % 3]   여기서 nth = 슬롯 «인덱스» (line 1941 의 i)
```

⛔ **`nth` 가 사람에 안 걸린다.** 같은 칸에서 같은 이동 유형이면 **다섯이 같은 틀을
지나므로 문장이 글자까지 같아진다.** 이것이 「전원 동일」의 기계적 뿌리다 —
주석이 *"연달아 같은 문장이 안 나오게"* 라고 적어놨는데, 그 「연달아」는
**한 사람 안의 세로 방향**이지 **다섯 사람의 가로 방향**이 아니다.

**`voice` 는 안 지어도 되는 것이 아니라 이미 있는 자리다** — `types.ts`·`schema.ts`·

진술 본문이 담는 것          생성    손저작
  타인 이름을 부르는 문단        0       22

★ **타인 언급 0 vs 22 가 「격자의 낭독」의 정확한 크기다.** 손저작은 *"즈안이랑
리솔이한테 제가 먼저 연락했어요"*·*"언니가 중간에 올라왔다 갔어요"* 처럼 **관계를
말하고**, 생성은 자기 좌표만 읽는다.

⛳ **동기 낱말 0은 둘 다다** — 이미 등재된 「떡밥 초반 부재」와 **같은 자리**이고,
경훈 말대로 **진술 방출기를 여는 김에 같이 닫아야 두 번 안 연다.**

> ⚠ **내 계수기가 여기서 한 번 0을 인쇄했다.** 첫 판은 이름 정확 일치로만 세서
> 손저작도 「타인 언급 0」이 나왔다 — 연습실은 「즈안」·「리솔」처럼 **성을 뗀 애칭**을
> 쓴다. 뒤 두 글자까지 보게 고쳐서 22가 됐다. `proof.ts` R3 이 *"성을 뗀 꼴로
> 찾는다"* 고 이미 적어둔 규약을 내 계수기만 안 따랐다.

## §4 제약 지도 — 진술은 관측 표면의 본체다

### ⛔ 건드리면 안 되는 명제 (늘릴 때 깨지면 게임이 깨진다)

| # | 명제 | 무는 곳 |
|---|---|---|
| ① | **무고한 자의 진술 = `presence`** (거짓말은 범인만, 그리고 하나) | `verifier.ts:768` §7.5 · `solver.ts:105` 가 `claim ?? presence` 로 진실을 고정한다 |
| ② | **범인의 진술 ≠ 진실 동선** (사망 칸에서 반드시 어긋난다) | `verifier.ts:794`·`:831` |
| ③ | **무고한 자가 사망 시간대에 현장에 있으면 안 된다** | `verifier.ts:818` — 기회가 생겨 유일성이 무너진다 |
| ④ | **진술이 `seedTerms`(조사로 얻을 단어)를 말하면 안 된다** | `verifier.ts:1585` §9-7 계열 · 지문도 같이 읽는다 |
| ⑤ | **진술이 주장한 슬롯·장소 라벨이 `presence`와 맞아야 한다** | `verifier.ts:1906` §9-12 — 산문과 격자가 갈리면 실패 |
| ⑥ | **문단 수가 사람마다 쏠리면 안 된다** | `verifier.ts:1530` — 길이가 곧 유용도 표시(§절대 규칙) |
| ⑦ | **지문 온도가 다섯이 고르게** | `verifier.ts:868` · §9-1 |
| ⑧ | **진술의 타인 언급이 「인물」 공란의 증명 경로가 된다** | `proof.ts:276` **R3 산문 지목** — 진술 문단을 읽어 성 뗀 이름을 찾는다 |

★ **⑧이 가장 조심할 자리다.** 지금 생성 진술은 타인을 0번 부르므로 R3 이 **한 번도
발화하지 않는다.** 살을 붙이며 이름을 부르기 시작하면 **R3 이 켜지고 증명 경로가
바뀐다** — 「인물」 공란이 조사 없이 풀리는 쪽으로 갈 수 있다.
**늘리기 전에 `proof-check`·`clue-check` 를 기준선으로 찍어두고 대조해야 한다.**

### ⚠ 검열관은 진술을 **안 본다**

`censor.ts` `passages()` 가 모으는 것은 `chapter.opening`·`chapter.epilogue`·
`chapter.report`·`reveal.narration`·`prologue`·`facts[].story` 다.
**`people[].statement` 는 관할 밖이다.**

```
matrix.ts:287  channel: statement · invariant: leak          status: covered   ← 검증기 §9-7 계열
matrix.ts:290  channel: statement · invariant: contradiction status: covered
matrix.ts:293  channel: statement · invariant: derivable     status: open      ★ 비어 있다
```

⛳ 「누설」과 「모순」은 **검증기**가 덮고 있어서 검열관 없이도 도는데,
**`derivable`(도출 가능성)만 열려 있다.** 진술에 살을 붙이면 **그 열린 칸이 커진다.**

### ✅ 늘려도 되는 자유 영역

```
자유          근거
말투·종결어미·문장 길이     ①~⑧ 어디에도 안 걸린다. voice 필드가 이미 그 자리다
심경·태도·딴소리          격자 명제를 안 건드리는 한 자유
「무엇을 하고 있었나」      장소·시각을 안 바꾸는 서술이면 ⑤와 무관
관계 한마디               ⚠ 조건부 — 이름을 부르면 ⑧(R3)이 켜진다
동기 암시                 ⚠ 조건부 — ④(seedTerms)에 걸리지 않는 낱말이어야 한다
물건·소지품 언급           ⚠ 조건부 — HERRING 은 소지품 검사가 드러낼 것이라 ④와 충돌 위험
```

**자유 영역의 경계가 곧 「닻 있는 재료」의 경계다** — 무해한 것(말투·심경)은 무제한이고,
**정보가 실린 것(이름·동기·물건)은 전부 조건부**다.

## §5 산정 — 수리 규모 (구현 안 함)

경훈이 낸 방향 넷을 위 제약에 비춰 크기만 잰다.

```
① 문장틀 풀        작다.  `nth` 를 슬롯 인덱스에서 «사람+슬롯»으로 바꾸고 틀을 늘린다.
                        제약 ①~⑦ 무관 · ⑧ 무관 (좌표만 말하므로)
② voice 팔레트     중간. 필드는 이미 있다(`schema.ts:308`). 팔레트에 규격을 받고
                        틀이 그것을 입는 층이 새로 필요하다. PALETTE-BRIEF 개정 동반
③ 살 비트          크다.  ⑧(R3)·④(seedTerms)에 직접 닿는다. **여기가 진짜 공사다.**
                        기준선(proof-check · clue-check · solve-check)을 먼저 찍어야 한다
④ 페어플레이 게이트  중간. 「범인만 다른 패턴 금지」는 새 검사다.
                        지금은 전원 동일이라 자동으로 참이고, ①을 하는 순간 필요해진다
```

★ **①과 ④는 한 벌이다.** 틀을 사람마다 갈리게 하는 순간 「범인만 다른 틀」이
가능해지므로, **①의 커밋에 ④가 같이 들어가야 한다.**

⛳ **③은 따로 연다.** 나머지 셋은 좌표만 만지고, ③만 정보를 만진다.
