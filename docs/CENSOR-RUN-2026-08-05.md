# 검열관 첫 실행 — 예상 판정 (실행 **전에** 적는다 · 2026-08-05)

대상: `engine/cases/closing-theater.yaml`

## ① 잡아야 할 것 — 의도된 프롤로그 불일치

```
프롤로그 ¶2          "다음 날 아침, 분장실에서 임소현이 발견됐다."
incident.scene_state "자정을 조금 넘긴 무렵, 분장실에서 발견됐다."
slots[2] = t2        "자정을 조금 넘긴 무렵"   ← 마지막 칸 = 발견 시각 (proof.ts R7)
```

**같은 사건의 발견 시각을 두 산문이 다르게 말한다.** 구조(t2)와 브리핑은 서로
정합이고 **프롤로그만 어긋난다.** 검열관이 이것을 올리면 ①성립.

★ 이것이 왜 코드로 못 잡히나: 프롤로그의 「다음 날 아침」은 **슬롯 라벨이 아니다.**
어떤 닻으로도 문자열 대조가 안 된다 — 매니페스토 §🔴 ⓐ 벽 5칸이 예약해둔 자리.

## ② 잡으면 **안** 되는 것 — 오늘 고친 한 줄 (오탐 시험지)

```
e_rec2.record  "빌려간 열쇠와 돌려준 시각이 적힌 장부. 그날 밤 한 줄은
                반납란이 비어 있었다. 적힌 자리는 로비."
```

오늘(2026-08-05) 내가 **구조와 맞추려고** 「적힌 자리는 로비.」를 붙였다.
지금은 `points_at: { location: hall }`(=로비) 과 정합이고, 3장 서술문
*"…남아 있었고, [로비]를 가리켰다"* 와도 정합이다.

- 검열관이 **안 건드리면** → 정상
- **흠으로 올리면** → **오탐이다.** 인용은 실재하므로 ⓐ 필터를 통과할 텐데
  판정이 틀린 것이고, 그것이 ⓐ의 한계를 보여주는 실측 데이터가 된다
