## 핵심 게임 모델 (건드릴 때 반드시 지킬 것)
- **게임이 플레이어 대신 추리하지 않는다.** 자동 모순감지·모순 경고·게임의 텍스트 강조·조사 추천·오답 개별 지목 전부 금지. (과거 정답 누설 사고 ~7회 → 전부 이 원칙 위반이었음. 형태만 바꿔 계속 재발하므로 기능 자체를 두지 않음.)
- **일회성 노출은 버그.** 공개된 텍스트/정보는 영구 재접근 가능해야 함(토스트는 "어디 생겼다" 신호만).
- **보고서 판정(현재 모델 — 3차 개정 반영 완료):**
  - **용어는 `장`(章)**. `항` 아님(구용어). 영문은 Section / Chapter.
  - 장 상태 = **잠김 / 열림 / 완성 / 완성·재개봉 사용됨**. `장 확인` 버튼 없음 — 공란 다 채우면 자동 `완성`+잠김.
  - **순차 잠금.** 1장만 열림 → 완성 시 다음 장 열림. **잠긴 장은 번호만 노출**(제목·공란 라벨·후보 유형·개수 전부 가림). 전체 진행도(`2/5장`)·잔여 조사만 노출.
  - **재개봉 장당 1회.** 완성 후 한 번 다시 편집 가능(`재개봉 사용됨` 표시). 이미 공개된 정보는 회수 안 함.
  - 실시간 채점 없음 + **모순 경고도 없음**(오답·모순에 완전 침묵). 되돌릴 수 없는 건 **최종 제출** 하나뿐. 제출 다이얼로그에 미채움 공란 개수 경고.
  - 정보 공개 트리거 두 종: **장 완성** / **특정 조사 실행**. 장 완성 시 `state.solved`(sticky) + `state.unread`/`toast` + invLog 기록.
  - **보고서는 서술 모드 단독.** 목록·보드 모드 없음(사용자 결정). 5장 도달 시 보드 자동전환도 없음.
- **공개 정보 유용도(yield): path / narrow / decoy / flavor.** decoy=참이지만 무관(레드 헤링). **decoy와 path를 시각적으로 구분 금지.** 산장 사건 decoy 비율 40%.
- **정보 층위 3종:** 확정(브리핑·확보물증, 실선·채움)/주장(진술, 따옴표·기울임·인물색)/판단(공란·상황판 연결, 입력필드·점선). 모순 판정은 확정 층 기준만.
- **조사:** 별도 화면 없음. 공간→현장 평면도 클릭, 인물→용의자 카드 버튼, 관계→관계 그래프 두 노드 선택. 잔여 예산 하단바 상시. 기록은 평면도·그래프에도 누적.
- **관계 그래프(`view:'graph'`)와 상황판(`view:'board'`)은 별개.** 관계 그래프=게임이 그리는 **확정** 관계망, **실선** 간선, 빈 상태 시작(추측 간선 안 그림). 상황판=플레이어 자유 배치 **판단** 캔버스, **점선** 연결. 시각 언어(실선/점선) 절대 섞지 말 것 — 가설을 확정으로 착각함.
- **물증 카드:** 필드 **발견·기록 2개만**(뜻 필드 금지). 기록은 3인칭 관찰만(위조·밀폐·가명 등 기능 판정 금지). 모든 카드 동등(결정적 단서가 더 길거나 화려하면 안 됨). 특수(메시지/문서)는 카드 하단에 덧붙임.
- **레드 헤링을 시각적으로 구분 금지.** 프로필 카드에 유죄 판정(O/X·유력) 금지 — 사실만.
- **하이라이트 4종(드래그): 표시/확인/의심/모순.** 표시=중립(azure), 툴바 첫 위치·원탭, 재선택 시 3종 승급. **격자 셀 마킹은 3종(확인·의심·모순)** — 배경 틴트+셀 **우측 점**으로 표시(좌측 바 아님, 인물 색과 위치 분리). 격자 빈 셀 = **"언급 없음"**(— 아님). 조사 결과가 격자 셀에 자동 표시되지 않음(모순 경고 부활 금지).
- **인물 색**은 전 화면 동일(진술 레일·격자 행·프로필·평면도 점·메모·상황판). 초상화 없음(v1은 색). 실존 인물명은 디자인 단계 임시.
- **읽기 표면 vs UI 표면 서체 분리 유지:** 진술 본문·프롤로그·결말 = 16px·행간 1.85+ / 격자·프로필·조사기록 = 13–14px·조밀.

## 상황판 인라인 (dc-import 제거 — 플레이테스트 단일파일)
과거 export가 `dc-import` 자식을 안 따라가 상황판이 번들에서 통째 빠졌음 → **`추리판.dc.html`을 `추리게임.dc.html` 안으로 인라인하고 dc-import 제거**. 방식: 자식 템플릿은 `isBoard` 블록에 그대로 붙이되 top-level 홀을 `{{ pb.* }}`로 네임스페이스, `.pb-*` 스타일은 helmet으로, 자식 로직은 부모 클래스에 병합하되 멤버명 `PB_*` 접두사·상태는 `state.pb` 단일 객체로 격리(부모 `state.sel` 등과 충돌 방지). setState→`PB_set`(pb 머지), renderVals→`PB_render()`(부모 renderVals에서 `view==='board'`일 때만 호출해 `pb`로 노출). seed/lang 배선: 자식의 `props.seed`→`this.buildBoardSeed()`, `props.lang`→`this.state.lang`로 치환(부모 값 직결). Delete/Backspace 삭제 리스너는 `PB_key()`가 board 진입 시 지연 설치. on-jump은 현 자식에 호출부 없음(`boardJump` 인스턴스에 살아있음). 자식 수정 시 이 인라인 사본도 같이 갱신.

### 단어 카드 출처 표기 정정 (provenance 문구 = 실제 획득 경로 일치)
획득 경로를 바꾼 뒤 카드에 찍히는 출처 문구를 맞춤. TERM_INFO: `유서` fk→`소지품 검사 · 문세라`/fe→`Belongings · Sakura`; `김선생` fk→`별채 수색 · 소지품 검사`/fe→`Annex search · belongings`; `마약` fk→`소지품 검사`/fe→`Belongings search`; `폭로 임박` fk→`별채 수색 · 소지품 검사`, dk→`기록에 남은 메시지가 같은 시점을 가리켰다.`, fe/de도 대응. CLUE_MAP: `search:annex`의 ko를 `거래 기록 (별채 대포폰)`으로(판정어 `정체` 금지·`대포폰` 잔재 제거), `belongings:wonyoung`에 `{p:'sakura',slot:'motive',ko:'추적 중이던 번호와 일치하는 연락처'}` 추가(정체=세라가 별채·리원 소지품 두 경로 모두 프로필에 뜨도록). 물증 기록(dk/de)은 3인칭 관찰만 — 위조·가명·밀폐 등 판정어 금지.

**미정리 1건:** `fixture:safe` 결과문이 아직 "금고에서 윤다인 명의 위장 유서 초안이 나왔다"인데,
`belongings:sakura`도 유서를 준다. 같은 유서가 두 곳에서 나온다. 엔진은 세라 소지품 하나뿐.
금고를 무엇으로 만들지가 설계 결정이라 보류 중 — `docs/MEMORY.md` 미해결 표 참조.

## 현장 평면도 엔진 — ①② 완료 / ③ 보류
`buildFloorplan`이 이제 `GEO` 스키마(buildings·rooms[벽공유 사각형]·zones·doors·windows·walks·fixtures, viewBox 0 0 1000 625)를 소비하는 **공용 지오메트리 엔진**. %-박스 렌더러 폐기.
- **자동 렌더:** poché(건물 bbox 외곽 굵은선+얇은 내부선) · 내부벽(방 공유 엣지에서 파생, 내부 문 span 빼기로 자동 gap) · 문 스윙 아크(닫힘 leaf 선 + 힌지 회전 90° 호, sweep 자동계산) · 외부문은 poché 위 bg-subtle erase로 gap · 창문 3선(세그먼트 수직 오프셋 ±3) · 진입로 해칭 · 자택 offsite 점선 · 시신 **X** · 축척바. SVG 지오메트리 + HTML 오버레이(클릭/텍스트) 분리, viewBox→% 변환.
- **상태 바인딩 무손상:** room/zone은 `loc`(main/room/annex/approach/home)로 기존 로직(CLAIM_LOC·FLOOR_CLUES·search·invLog·FIXTURES·invStatusFor)에 매핑. 본채=거실+부엌(loc main)+다인의 방(loc room), 벽공유 사각형. **거실·부엌=우측 공용부(정문·후문이 여기로 진입), 다인의 방=좌측 안쪽(거실에서 방문으로)** — 외부문이 사적 공간으로 바로 뚫리지 않게. 조사 틴트(scene=적/found=accent/searched=green, scene 우선)·인물 점(loc anchor room)·별채 gated:s1·clue chip·provenance 배지 전부 room id 기반. 인물 점 anchor는 loc별 primary area.
- **신규 사건 이식:** 캠페인=`GEO` 손 authoring, 생성/일일 사건=생성기가 같은 스키마 emit(rooms 벽공유+doors/windows 세그먼트+fixtures xy)하면 자동 렌더. `LOCATIONS`(loc 플래그)·`FIXTURES`(loc/icon/body/labels)·`WALK`는 유지, `WALK`는 이제 미참조(GEO.walks가 대체).
- **③ 종결(기존 유지):** 공용 물증 아이콘 세트 재드로우는 미리보기 3안(라인/라인+솔리드/솔리드·은유우선안)까지 검토 후 **기존 세트 유지로 결정**. 단 기존에 `연탄`·`화로`가 동일 글리프였던 것만 **화로=불꽃 얹은 화로**로 교체해 구분. `ICONS`는 그 외 그대로.
