# Handoff: Nobody Lies · 노바디 라이즈 (추리 게임)

## Overview
정지된 살인 사건(산장 살인사건)을 플레이어(무명의 수사관)가 진술·조사·보고서로 푸는 추리 게임. 계보: Return of the Obra Dinn → The Case of the Golden Idol. 게임명 **Nobody Lies / 노바디 라이즈**, 태그라인 "모든 진술을 의심하라". 이 빌드는 산장 사건 1개 데모.

## About the design files — 읽는 법
**이건 "디자인 목업"이 아니라 실제로 동작하는 앱 소스다.** HTML로 작성됐지만 프로토타입이 아니라 완성 게임의 구현체. 별도 빌드 스텝 없이 브라우저에서 바로 실행된다(번들러·npm 없음). Claude Code는 이 소스를 **읽고 편집**하면 된다 — 다른 프레임워크로 재작성할 필요 없음. (원한다면 React/네이티브 등으로 포팅하는 것도 가능하나, 요청받기 전엔 하지 말 것.)

## Fidelity
**Hi-fi, 완성 구현.** 최종 색·타이포·간격·인터랙션·게임 로직이 전부 들어 있다. "이렇게 생겨야 한다"가 아니라 "이렇게 동작한다"이다.

## 어떻게 실행하나
- **가장 쉬움:** `Nobody Lies (노바디 라이즈).html` 더블클릭 → 완전 오프라인 단일 파일(3.4MB). 편집 불가·실행 전용.
- **소스 실행/편집:** `추리게임.dc.html`을 로컬 정적 서버로 연다(예: `python3 -m http.server` 후 해당 파일 열기). `file://` 직접 열기는 `_ds`·`support.js` 상대경로 fetch가 막힐 수 있으니 정적 서버 권장.
- 편집은 `추리게임.dc.html`만 고치면 됨. 저장 후 새로고침.

## 아키텍처 (Design Component / "DC")
- 앱 전체가 **단일 DC**: `추리게임.dc.html`. 구조 = `<x-dc>…</x-dc>`(템플릿) + `<script data-dc-script>class Component extends DCLogic {…}</script>`(로직).
- `support.js` = DC 런타임(프로젝트가 써주는 파일, **수정 금지**). `<x-dc>`를 파싱해 React로 렌더. 템플릿 문법:
  - `{{ dotted.path }}` = 값 홀(표현식 불가, 점 경로만). 값은 `renderVals()`가 반환.
  - `<sc-for list="{{ items }}" as="it">…{{ it.x }}…</sc-for>` = 반복.
  - `<sc-if value="{{ flag }}">…</sc-if>` = 조건.
  - 이벤트/스타일은 통짜 속성: `onClick="{{ handler }}"`, `style="{{ obj }}"`(React style 객체).
  - `<x-import component-from-global-scope="VectorDesignSystem_490b73.Button" …>` = 디자인 시스템 컴포넌트 마운트.
- 스타일은 **인라인 위주**. `<helmet>`의 `<style>`엔 `@keyframes`·스크롤바·`.pb-*` 등 인라인 불가한 것만.
- 로직 클래스는 React 클래스 컴포넌트와 동일(`this.state`/`setState`/lifecycle) 단 `render()` 대신 `renderVals()`가 템플릿 입력을 반환.

## 핵심 게임 모델 (구현·수정 시 반드시 지킬 불변식)
> 개발 중 7회 재발한 사고가 전부 아래 위반이었음. 형태만 바꿔 계속 터지므로 기능 자체를 두지 않는다.
- **게임이 플레이어 대신 추리하지 않는다.** 자동 모순감지·모순 경고·정답 강조·조사 추천·오답 지목 전부 금지. 최종 제출 전까지 게임은 채점·피드백에 **완전히 침묵**.
- **레드 헤링(decoy)과 정답(path)을 시각적으로 구분 금지.** 똑같이 생겨야 함. 프로필에 유죄 판정(✓/유력) 금지 — 사실만.
- **일회성 노출 금지.** 공개된 정보는 영구 재접근 가능(토스트는 "어디 생겼다" 신호만, 내용은 해당 화면에 영구 + provenance 배지).
- 보고서 = **장(章) 단위 순차 잠금**. 1장만 열림 → 공란 다 채우면 자동 완성+다음 장 열림. 잠긴 장은 번호만 노출. 재개봉 장당 1회. 되돌릴 수 없는 건 최종 제출뿐.
- 정보 층위 3종: **확정**(브리핑·확보물증, 실선/채움) · **주장**(진술, 따옴표/기울임/인물색) · **판단**(공란·상황판, 입력필드/점선). 실선(확정)과 점선(판단)을 절대 섞지 말 것.

## Screens / Views (모두 `추리게임.dc.html` 안의 `view` 상태)
홈 → 사건 상세 → 플레이(프롤로그 → 브리핑 → 진술 정독 → 자유 진행). 사이드바 뷰:
- **사건 개요(overview)** · **보고서(narrative)** — 서술 모드 단독, 공란 채우기 · **진술(statements)** — 원문 정독 · **용의자(profile)** · **현장(map)** — 평면도/도식 세그먼티드 토글 · **관계 그래프(graph)** — 게임이 그리는 확정 관계망(실선) · **상황판(board)** — 플레이어 자유 배치 판단 캔버스(점선) · **조사 기록(log)** · **메모(memo)** · **표기 안내(reference)**.
- 우측 디테일 패널 3탭 고정(진술/조사기록/메모 = 주장/확정/판단 층위). KO/EN·다크/라이트 지원.

### 현장 평면도 엔진
`buildFloorplan()`이 `GEO` 스키마(buildings·rooms[벽 공유 사각형]·zones·doors·windows·fixtures, viewBox 0 0 1000 625)를 소비하는 공용 지오메트리 엔진. poché 외벽·내부벽 파생·문 스윙 아크·창문 3선·해칭·시신 X·축척바를 자동 렌더. 신규 사건은 같은 스키마만 emit하면 자동 렌더.

### 상황판(board) — 인라인됨
원래 자식 DC(`추리판.dc.html`)였으나 **단일 파일 export 요구로 부모(`추리게임.dc.html`)에 인라인**됨. 규약: 템플릿 홀은 `{{ pb.* }}` 네임스페이스, `.pb-*` 스타일은 helmet, 로직 멤버는 `PB_*` 접두사, 상태는 `state.pb` 단일 객체로 격리. `추리판.dc.html`은 **참조용**으로만 동봉(더 이상 import 안 됨) — 상황판을 고치려면 부모의 인라인 사본(`PB_*`/`state.pb`)을 고쳐야 함.

## Design Tokens
새 토큰·색을 만들지 말 것. **Vector Design System** 사용: `_ds/vector-design-system-490b734e-7df2-4af7-b176-9c91211b1ef6/`. 모든 색·타이포·간격은 `var(--*)` 토큰(`colors_and_type.css`). 다크 우선. 게임 전용 색만 `[data-surface="vector"]` 스코프에 `--g-*`로 추가돼 있음(`--g-confirm`·`--g-suspect`·`--g-contradict` 등). 폰트 Pretendard(+Inter 폴백). 상세는 `_ds/.../README.md` 참조.

## Files (동봉)
- `추리게임.dc.html` — **메인**. 거의 모든 화면·로직·상황판(인라인)·데이터.
- `추리판.dc.html` — 상황판 원본 자식 DC(참조 전용, 미사용).
- `support.js` — DC 런타임(수정 금지).
- `_ds/…` — Vector 디자인 시스템 번들·CSS.
- `Nobody Lies (노바디 라이즈).html` — 오프라인 단일 실행본(읽기/편집용 아님).
- `CLAUDE.md` → 동봉본 `PROJECT_NOTES.md` — 프로젝트 인계 노트(불변식·데이터 동기값·대공사 이력의 원본 소스). **작업 전 반드시 읽을 것.**

## 최근 변경(이 핸드오프 시점)
1. 상황판을 부모에 인라인, `dc-import` 제거(단일 파일 export가 자식을 안 담던 버그 해결).
2. 데이터 동기화: b15=오나경, b20 추가(문세라)로 4장 공란 5개, TERM_MAP 갱신, `대포폰` 제거(별채 수색=`별채 대포폰`만), `폭로 임박`은 물증 유래, autopsy 조사비 1. 필수 조사 3(부검·세라 소지품·별채 수색)+마약용 1 = 최소 4 ≤ 예산 5로 완주 가능.
3. 단어 카드 출처 표기 정정: TERM_INFO(유서·김선생·마약·폭로 임박)와 CLUE_MAP(별채 수색 = '거래 기록 (별채 대포폰)', 판정어 '정체' 제거)를 실제 획득 경로에 맞춤. 김선생 정체는 별채 수색·리원 소지품 두 경로가 프로필에 뜨도록 CLUE_MAP에 세라 motive 항목 추가.
