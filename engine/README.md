# Nobody Lies · 검증기

**이것은 프로덕션 앱이 아니다.** 사건 데이터가 논리적으로 성립하는지 검사하는 프로토타입이며, 프로덕션 구현의 **이식 원본**이다.

```
npm install
npm run verify
```

## 파일

| | |
|---|---|
| `src/types.ts` | 사건 데이터 스키마 정본 |
| `src/verifier.ts` | 검증 알고리즘 |
| `src/cases/mountain-lodge.ts` | 산장 살인사건 — 골든 케이스 |
| `src/cli.ts` | 검증 결과 출력 |
| `templates/` | 사건 저작 서식 |

## 검증 항목

| | 내용 |
|---|---|
| 유일성 | 동기 ∧ 기회 ∧ 수단이 성립하는 인물이 정확히 1명 |
| 트릭 허점 | `flaw`가 존재하는가 |
| 다중 경로 | 핵심 사실의 획득 경로가 2개 이상 |
| 시작 가능성 | 조사 없이 확정 가능한 장이 있는가 |
| 교착 | 순차 진행 중 막히는 지점이 없는가 |
| 지목 공란 | 정확히 1개 · 답이 범인과 일치 · 조사 없이 확정 불가 |
| 조합 수 | 지목 장의 조합이 30 이상 (찍기 방지) |
| decoy | decoy가 fact를 제공하지 않는가 |
| 확보 단어 | `discovered` 공란의 답이 실제로 획득 가능한가 |
| 부문 분포 | 물증 · 정황 · 심증 각각 존재 |
| 조사 비율 | 조사 대상 ≥ 예산 × 3 |

## 산장 사건 현재 상태

```
5장 19공란 · 조사 대상 23개 / 예산 5 (4.6배)
최단 2회 · 기대 5회 · 난이도 hard
부문: 물증 7 · 정황 9 · 심증 3
decoy 비율 40%
검증 통과
```

경고 1건: `기대 5회 + 여유 1 > 예산 5`. 의도된 긴장이며 사양 결정 대기.

## 런타임에 필요한 것 / 아닌 것

**런타임**: `deriveFacts`, 장 완성 판정, 트리거 평가, 채점

**저작 시점에만**: 유일성 · 교착 · 조합 수 · decoy · 경로 계산. **UGC 에디터를 만들 때 필요하며 v1 플레이에는 불필요하다.**

## 기대 경로 공식

```ts
typicalCost = ceil(단서추종경로 × 1.5)
```

**임시값이다.** 실측 데이터로 보정해야 하며, 이 값의 정확도가 생성기 신뢰도를 결정한다.
