# 세계 팔레트 의뢰 서식 (Claude 웹에 붙여 넣는 것)

> **이것이 주력 경로다.** LLM은 **어휘만** 만들고, 사건의 논리(범인·트릭·격자·
> 물증·조사·공란·예산)는 전부 코드가 만든다.
>
> ```
> PALETTE-BRIEF  →  palette.json  →  generateCase(seed, palette)  →  verify  →  사건 N개
>     LLM 1회                            코드                        관문
> ```
>
> **LLM 호출은 사건 수가 아니라 세계 수에 비례한다.** 팔레트 하나로 seed 만
> 바꾸면 사건이 계속 나오고, 뼈대가 검증된 것에서 나오므로 **통과율이 구조적으로
> 100%다**(2026-07-29 실측: 200/200).
>
> 비교 — `CASE-BRIEF.md` 는 LLM에게 논리까지 시킨다. 골든 케이스를 손으로 늘릴
> 때나 팔레트가 못 만드는 특이한 사건에만 쓴다.

## 쓰는 법

```bash
# 1. 아래를 복사해 Claude(웹)에 붙여 넣고 JSON 을 받는다
# 2. engine/templates/my-palette.json 으로 저장
# 3. 돌린다
npm run verify -w engine -- --generate 40 --palette templates/my-palette.json

#    난이도를 고르려면 (선호 순서)
npm run verify -w engine -- --generate 40 --palette templates/my-palette.json --want normal,hard
```

예시: [`palette-example.json`](palette-example.json) (심야 라디오 방송국)

## 가장 중요한 것

**당신은 사건을 만들지 않습니다.** 범인·트릭·동선·물증·정답은 전부 프로그램이
정합니다. 당신이 주는 것은 **그 프로그램이 골라 쓸 단어들**입니다.

그래서 **어느 것이 정답에 쓰일지 당신도 모릅니다.** 이것이 규칙 하나로 이어집니다:

> **목록 안의 항목은 전부 같은 무게여야 합니다.**
> 「이게 진짜 흉기 같다」거나 「이 동기가 제일 그럴듯하다」가 티나면, 프로그램이
> 무엇을 고르든 플레이어는 목록만 보고 답을 좁힙니다. 그게 정답 누설입니다.

## 채울 것

```json
{
  "setting": "무대 이름 (예: 심야 라디오 방송국)",
  "names":   ["8개 이상 — 한국식 이름. 실존 인물 금지"],
  "jobs":    ["6개 안팎 — 그 무대에 있을 법한 직업"],
  "items":   ["6개 안팎 — 그 무대의 일상 물건"],
  "motives": ["4개 안팎 — 짧은 명사구"],
  "places":  { "hall": "사람들이 모이는 곳", "room": "사건 현장", "away": "부지 밖" },
  "times":   { "t0": "사건 전", "t1": "사망 추정 구간", "t2": "발견" }
}
```

### 항목별 주의

| | |
|---|---|
| `names` | 8개 이상. 그중 셋이 용의자, 하나가 **기록에 남은 이름**으로 쓰입니다. 성별·연령대가 섞이게 |
| `jobs` | 무대와 관계가 있어야 합니다. 「그 사람이 왜 거기 있었나」가 설명돼야 하니까요 |
| `items` | **판정어 금지.** 「흉기」·「독극물」 같은 이름을 쓰지 마세요. 「보온병」·「큐카드」처럼 **그냥 물건**이어야 합니다 |
| `motives` | 「채무 관계」·「자리 다툼」 정도의 짧은 명사구. 문장으로 쓰지 마세요 |
| `places` | **셋 다 필수**입니다. `room` 이 현장이고 `away` 는 부지 밖입니다 |
| `times` | 가운데(`t1`)가 사망 추정 구간입니다. 셋이 **시간순**이어야 합니다 |

### `places.room` 은 다섯 트릭을 전부 견뎌야 합니다

프로그램이 **위장 자살 · 밀실 · 알리바이 위조 · 시신 이동 · 지연 장치** 중
하나를 고릅니다. 어느 것이 걸릴지 모르므로 `room` 은 이런 곳이어야 합니다:

- **문과 창이 있는 실내** (밀실·위장 자살이 창턱과 잠금장치를 씁니다)
- **`hall` 에서 걸어서 갈 수 있는 곳** (시신 이동이 끌린 자국을 씁니다)
- **물건을 미리 놓아둘 수 있는 곳** (지연 장치가 씁니다)

야외·차량·엘리베이터처럼 이 중 하나가 성립하지 않는 곳은 피하세요.

## 출력 형식

**JSON 하나만** 주세요. 설명 없이 바로 코드블록으로. 주석 금지(JSON 이므로).
한국어로 씁니다.

## 팔레트가 못 바꾸는 것 (지금은)

구조는 `daily` 고정이다 — **용의자 3 · 장소 3 · 시간대 3 · 2장 7공란 · 조사 11.**
팔레트는 그 자리에 들어갈 **이름표**만 바꾼다.

바뀌는 것은 트릭(5종)과 그에 딸린 전용 물증·조사·**범인의 동선**이다.
`delayed_mechanism` 은 범인이 사망 구간에 현장에 없다 — 격자 모양이 다르다.

> **다음에 넓힐 자리**: 인물 수 · 장 수 · 슬롯 수를 팔레트가 정하게 하는 것.
> 지금은 `generateCase` 가 3인·2장으로 고정돼 있고, campaign 규모(5인·5장)는
> `SYSTEM-DECISIONS.md` 가 「조합으로 만들면 실패율이 급등한다」고 적어둔
> 미결이다. 다만 **지금 통과율이 100%라 그 판정을 다시 잴 근거는 생겼다.**
